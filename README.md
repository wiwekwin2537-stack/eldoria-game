### v5.33 (2026-10-19) — แยกท่าป้องกันกับฮีล ใช้กติกาเดียวกันทุกโหมด
- ปราการเทพและออร่าพาลาดินลดดาเมจตามเดิม แต่ไม่ฟื้นเลือดให้ตัวเองหรือเพื่อน; ท่าฮีลหลักและบัฟฮีลพระยังทำงาน

- ผลตรวจ: Node 15 ชุด + Chromium 3 ชุดผ่าน (รวมบทบาทสกิล 26 กรณี), syntax 210 ไฟล์ผ่าน และตรวจอิสระแล้ว. เจ้าของอนุมัติอัปชุดนี้แล้ว; ยังไม่ยืนยันสมดุลจากผู้เล่นจริงหรือ QA ทั้งเกมที่เคยค้างช่วงแผนที่

### v5.32 (2026-10-19) — ปิดเฉพาะเลือดเด้งอัตโนมัติใน PvP/สู้บอส
- เจ้าของปรับคำสั่งหลังพิจารณาผลต่อพระและพาลาดิน: ปิดเฉพาะรีเจนอัตโนมัติจาก base/อาชีพ/พาสซีฟ/อุปกรณ์; สกิลฮีลที่กดใช้ บัฟฮีล ฮีลจากเพื่อน และอัลติทำงานเดิม โดยใช้มานาและคูลดาวน์ตามเดิม
- `passiveRegenBlocked()` ใน `js/014-core.js` ตรวจ PvP และบอสที่กำลังต่อสู้ในฉาก; เก็บการทำ/รับดาเมจล่าสุดด้วย `srvNow()` ตามช่วงพักเดิม `BAL.regenDelay` ป้องกันยิงไกลนอกระยะไล่แล้วรีเจนต่อเนื่อง
- แก้เฉพาะจุดรีเจน 4 แหล่ง: base, passive อาชีพ, PTX (รวมอุปกรณ์/อัญมณี), พาลาดินติดตัว; ค่าฮีล/มานา/คูลดาวน์/ดาเมจเดิม ไม่ปรับตัวเลขสมดุลโดยยังไม่มีผลวัด
- เก็บข้อมูลบอสไปกับกระสุนและข้อมูลดาเมจที่ส่งให้เครื่องอื่น; mirror รับ aggro=0 ได้เพื่อให้รีเจนกลับมาหลังพ้นต่อสู้
- เทสก่อนแก้ยืนยันพาลาดิน PvP ฟื้น 50 HP/0.5 วิ; เทสฉบับห้ามฮีลทุกชนิดล้มที่กดฮีลใน PvP. ชุดล่าสุดผ่าน Node 15 ชุดและ Chromium สำหรับ PvP/บอสกับหน้าอันดับ; เพิ่ม REG136 รีเจนถูกปิดแต่สกิลฮีลใช้ได้
- หน้าเกม v5.32 แคช v134; ยังไม่ได้วัดความสมดุลผู้เล่นทุกอาชีพจริงหรือยืนยัน QA ทั้งเกมที่เคยค้างช่วงแผนที่. เจ้าของอนุมัติอัป GitHub แล้ว; ยังไม่ยืนยันผล deploy บน Render
