# ตำนานเอลโดเรีย

เกมออนไลน์2Dบนเว็บ งานปัจจุบันคือดูแลเกมเดิมและรวมโค้ดที่เขียนทับกันให้เหลือหน้าที่ละระบบเดียว ตามคำสั่งเจ้าของล่าสุด ขอบเขตเอโดเรียเมืองเดียว; การตัดเมือง2ในเกมเดิมยังเป็นงานเปิด

## เริ่มงาน
- `AGENTS.md`: คำสั่งทำงานฉบับเดียว
- `TASKS.md`: งานเปิดและการจองเท่านั้น
- `SYSTEMS.md`: แผนที่โค้ดที่ใช้อยู่
- `GAME_DESIGN.md` และ `STORY.md`: กติกาและเนื้อเรื่อง

## โครงสร้าง
| ส่วน | ตำแหน่ง |
|---|---|
| หน้าเกม/ลำดับโหลด | index.html |
| เกมเดิม | js/ |
| ภาพ | assets/ |
| server | server.js, accounts.js, world.js, pvp.js, party.js, market.js |
| แคชและการปล่อยรุ่น | sw.js, tools/pin_cdn.sh |
| เทสถาวร | tests/ |

## ตรวจในเครื่อง
เมื่อเจ้าของอนุญาตให้ตรวจ ใช้ `tests/quick.sh` กับเทสที่เกี่ยวข้องและเส้นทางผู้เล่นตามAGENTS ขณะนี้ยังพักการรันเกมและเทส ไม่แปลผลสแกนข้อความเป็นผลผ่านruntime

ไม่เก็บกองประวัติอัปเดต/รายการงานปิดในไฟล์นี้ ใช้สถานะปัจจุบันในTASKS และหลักฐานในโค้ด/เทส/ประวัติรุ่นแทน
