- ล็อกอินล่าสุดมีสิทธิ์บันทึก; แต่ละหน้าเกมมีสิทธิ์เฉพาะหน้า (document lease) ปฏิเสธคำสั่งที่ส่งช้าจากหน้า/เครื่องเก่า รวมWebSocket. เครื่องเก่าหยุดที่หน้าล็อกอิน ไม่reloadวน
- ลองCASใหม่เมื่อล็อกอินชนกับการบันทึก/จดหมาย/เหรียญ โดยไม่ทับข้อมูลล่าสุด; คงประวัติเซฟ20รายการ การตรวจrevision และการยืนยันหลังคำตอบหาย
- ส่งเซฟระหว่างเล่นทุก3วินาทีเมื่อข้อมูลเปลี่ยน และหลังเรียกบันทึก150ms; ต่อคิวข้อมูลล่าสุดขณะส่งเดิมอยู่. ตอนซ่อน/ปิดหน้าส่งkeepaliveได้พร้อมคำขอเดิม โดยเซิร์ฟเวอร์รับเฉพาะลำดับใหม่ของหน้าเดียวกัน
- บีบอัดคำขอใหญ่ด้วยgzipและตรวจUTF-8/ขนาดหลังคลาย; เพิ่มป้ายสถานะที่แสดงผลยืนยันเซิร์ฟเวอร์จริง. การปิดระบบก่อนส่งหรือก่อนเซิร์ฟเวอร์ยืนยันยังไม่ใช่การบันทึกที่รับประกันได้
