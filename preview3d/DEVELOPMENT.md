# จุดทำต่อ Eldoria 3D — ทดลองเดิน v0.2

## เป้าหมายและฐาน

เจ้าของสั่งทำต่อเนื่อง: 3Dทั้งหมด, สไตล์Eldoriaเดิม, โลกกว้างขึ้น, ไม่คัดลอกสูตรหรือเขียนทับ2D, ทดสอบก่อนส่ง เก็บ main ที่ v5.98 `da313af7cd51956b63a01d94dd5a5efbf799480a` และสาขาสำรอง `backup/eldoria-2d-v598-20261026` พัฒนาเฉพาะ `feature/eldoria-3d` / draft PR #3 ไม่ merge main หรือแก้ Render อัตโนมัติ

สำรองแล้วเฉพาะโค้ด/assetในGit ไม่เคยเข้าถึงหรือสำรองฐานข้อมูลจริง

## เปิดและทดสอบ

- `node tools/serve-3d-preview.cjs` → `http://127.0.0.1:8790/`
- `PREVIEW_PORT` เปลี่ยนพอร์ต; ค่าเริ่มต้น bind127.0.0.1เท่านั้น ไม่มีโฮสต์เล่นมือถือสาธารณะ
- `ELD_CHROMIUM=<browser> bash tests/quick.sh tests/preview3d_browser_test.js tests/preview3d_walk_test.js`
- เบราว์เซอร์ทดสอบต้องรองรับ WebGL สำหรับเครื่องนี้ใช้Chromium153/SwiftShader ไม่ใช่มือถือจริง

## สิ่งที่ทำได้แล้ว

- เมืองอ้างอิง44×34, โลกทดลอง88×68 พร้อมป่านอกเมือง ลำน้ำ สะพาน แร่ และmesh3Dจริง
- กล้องเมือง/ป่า/โชว์โมเดล หมุน/ซูม/ขอบเขตแมพ และ **เดินสำรวจ** พร้อมกล้องตามผู้เล่น
- เดินด้วยWASD/ลูกศรหรือjoystickจอสัมผัส; Ctrl/ปุ่มวิ่ง; หยุดเมื่อปล่อย/ยกเลิกtouch/สลับมุมมอง/แอปเสียfocus
- เดินออกนอกกรอบเมืองเดิมจริงได้; ชนอาคาร ต้นไม้ แร่ น้ำ ขอบโลก และฐานอาคารเดิม ไม่เดินทะลุทั้งหมด
- จังหวะขาคนเดินตามสถานะและเฟสเดิน; เงาและวัสดุเป็นmeshไม่ใช่แผ่นsprite
- ใช้instancingรวมฉากนิ่ง; คนที่ควบคุมและโมเดลสาธิตยังแยกสำหรับอนิเมชัน

## ไม่เขียนกติกาเดินซ้ำ

`tools/legacy-movement.cjs` อ่านsourceจริงจาก2Dเมื่อขอ `/legacy-motion.js`:
- `moveSlide` กับ `slideAxis` จาก js/031-core.js แถว1570–1575
- loopตรวจเท้าสี่มุมของtown collisionจากjs/031-core.jsแถว1576
- นิพจน์ความเร็วเดินจากjs/070-core.jsลูปหลัก

ตรวจSHA256แต่ละsourceที่อ่านกับฐานที่auditไว้ก่อนส่งmodule หากsourceเปลี่ยนจะตอบ503ให้reviewก่อน ไม่ใช้regexกว้างแล้วเงียบรับโค้ดใหม่ ไม่มีevalบนserverหรือคำสั่งจากผู้เล่น ไม่มีไฟล์คัดลอกbodyกติกาเดินอีกชุด

`walk.js` เป็นinput/coordinate adapterเท่านั้น เรียกสูตรเดิมด้วยสถานะทดลองกลางๆ: agi0, fa100, hu100, carry multiplier1 ไม่มีลดความหิว/เหนื่อย/บัฟ/อุปกรณ์หรือจำลองระบบบัญชีใหม่ ยังไม่ใช่playerTickทั้งหมด

ตรวจwrapperแล้ว: js/038-fix7.jsห่อmoveSlide/slideAxisเพื่อINPT10สำหรับว่ายน้ำ, dhitมีชั้นล็อกทางไปฉากอื่นใน031/146-fix114/171-fix144 รุ่นทดลองนี้ไม่ใช้ระบบว่ายน้ำหรือเปลี่ยนฉาก; ไม่อ้างว่าเชื่อมgate/สกิล/สถานะเดิมครบ

## แหล่งข้อมูลโลกเดียว

`world.mjs` สร้างตำแหน่งวัตถุและgridเดียวให้renderer+collision ใช้fixtureเดิม `tests/fixtures/town_layout_v536.json` ซึ่งผ่านเทสเทียบv5.98แล้ว แกนเมืองเลื่อนพิกัดเข้ากลางโลกใหม่โดยไม่ยืดสเกล ขอบเดิมเปิดสู่พื้นที่ขยาย และมีขอบโลกใหม่

ช่องชนเดิมที่ยังไม่มีโมเดลละเอียดใช้ฐานหินที่มองเห็นจริง153ช่องจากlegacySolids (ห้ามสร้างกำแพงล่องหน) ข้อมูลโลกนี้เป็นโลกทดลองในหน่วยความจำ ยังไม่ใช่สถานะโลกออนไลน์หรือจำนวนทรัพยากรจริง

## การแยกจากเกมจริง

hostอ่านอย่างเดียวแบบallowlist ไม่import server/accounts ไม่มีWebSocket/APIsave/load ไม่มีlocalStorage/service worker ชุดเกม2D, package.json, corejs, serverและswเดิมไม่ถูกแก้

โลกและตำแหน่งทดลองอยู่ในRAM รีโหลดแล้วกลับspawn ไม่มีระบบเซฟใหม่และไม่มีการอัปเดตเซฟจริง
