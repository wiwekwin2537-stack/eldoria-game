# จุดทำต่อ Eldoria 3D — ต้นแบบภาพ v0.1

## ขอบเขตและฐานที่เก็บแล้ว

- เจ้าของสั่งเริ่มตามแผน 26 ตุลาคม 2026: 3D ทั้งหมด, สไตล์เดิม, พื้นที่กว้างขึ้น, แยกไฟล์ 2D เพื่อกลับได้, ไม่เขียนระบบซ้ำหรือทับงานคนอื่น
- ฐานเกม 2D: `da313af7cd51956b63a01d94dd5a5efbf799480a` (v5.98)
- สำรองโค้ดและ asset ไว้บน `backup/eldoria-2d-v598-20261026`; พัฒนาเฉพาะ `feature/eldoria-3d`
- ไม่มีการแก้ main, ไฟล์ gameplay 2D, เซิร์ฟเวอร์เดิม หรือ Render; ยังไม่ได้สำรองหรือเข้าถึงฐานข้อมูลผู้เล่นจริง อย่าอ้างว่าสำรองเซฟแล้ว
- ไม่มีการเปลี่ยนเลขเวอร์ชันหน้า 2D/service worker เพราะยังไม่เผยแพร่รุ่น 2D ใหม่

## สิ่งที่ทำแล้ว

- `index.html`: หน้า 3D ภาษาไทยพร้อมเลือกเมือง/พื้นที่ขยาย/โมเดลและปุ่มกล้อง รองรับ touch
- `models.js`: mesh 3D ของคนมีข้อต่อ, มอนสไลม์, อาคาร, ปราสาท, น้ำพุ, ต้นไม้ และแร่ ใช้สีและองค์ประกอบจากเกมปัจจุบันเป็นแนวอ้างอิง ยังต้องเจ้าของประเมินสไตล์
- `app.js`: กล้องและแสง 3D, เมืองแกนเดิม 44×34, พื้นทดลอง 88×68, ป่าด้านนอกและจุดโชว์โมเดล รวม static geometry ด้วย instancing
- อ้างอิง layout จาก `tests/fixtures/town_layout_v536.json` โดยตรง ไม่คัดลอกตารางร้านอีกชุด ทดสอบ fixture นี้กับเกมฐาน v5.98 ผ่านแล้ว ข้อมูลนี้ไม่ใช่ snapshot ของผู้เล่นหรือสถานะออนไลน์ล่าสุด
- ใช้ Three.js r160 ที่มีอยู่ใน repo ผ่าน route แบบอ่านอย่างเดียว ไม่มี CDN/dependency runtime ใหม่; ก่อนพัฒนา renderer เต็มให้ประเมินเวอร์ชันและ asset pipeline โดยไม่อัปเกรดส่วนเกมเดิมพ่วงไปด้วย
- `tools/serve-3d-preview.cjs`: HTTP host แบบ allowlist แยกพอร์ต ไม่ import accounts/server ไม่รองรับ WebSocket หรือ API บัญชี ปฏิเสธการเขียน ไม่มี service worker และไม่ใช้ localStorage

## เปิดในเครื่อง

รันจากราก repo: `node tools/serve-3d-preview.cjs`
เปิด `http://127.0.0.1:8790/`
กำหนด `PREVIEW_PORT` เมื่อต้องการเปลี่ยนพอร์ต; ค่าเริ่มต้น bind loopback เท่านั้น ไม่เปิดให้เครื่องภายนอกเข้าถึง
สำหรับมือถือ ต้องจัดโฮสต์ทดลองคนละ origin ในขั้นถัดไป; ลิงก์ GitHub สาขานี้เป็นซอร์สโค้ด ไม่ใช่ลิงก์เล่นเกม

## สิ่งที่ยังไม่เสร็จ

1. **ยังเป็นต้นแบบภาพ** ไม่มีผู้เล่นเดินจริง collision ต่อสู้ ขุดแร่ ตัดไม้ รางวัล ออนไลน์ หรือเซฟ ภาพพื้นที่กว้าง4เท่ายังไม่ใช่แมพ gameplay ที่เสร็จแล้ว
2. โมเดลเป็นชุดต้นแบบ mesh รายละเอียดเบื้องต้น ยังไม่ได้รับอนุมัติสไตล์ ไม่มี texture/rig ครบทุกอาชีพหรือสัตว์
3. ยังไม่มีโฮสต์ทดลอง/ฐานข้อมูล 3D แยก จึงยังไม่มีลิงก์เล่นจากมือถือ
4. ยังไม่เชื่อมโมเดลกับกติกาเกมเดิม ห้ามสร้างระบบ combat/inventory/save ชุดใหม่เพื่อเร่งให้ดูเหมือนครบ
5. พื้นที่4เท่าเป็นค่าทดลองตามแผน ไม่ได้เพิ่มจำนวนจุดเกิดรางวัลหรือเปลี่ยนเศรษฐกิจ

## งานถัดไป

- ให้เจ้าของตรวจสไตล์ต้นแบบหนึ่งชุดก่อนผลิตทั้งเกม
- สำรวจ/ทำเทสพฤติกรรม movement, hit, moveSlide, playerTick, attack และ save/network จาก SYSTEMS.md และทุกชั้น wrapper ที่เกี่ยวข้อง แยก simulation ที่จำเป็นบนสาขา3D และใช้ adapter แปลงพิกัดไป renderer โดยไม่ซ้ำสูตร
- เชื่อมเดินและ collision ในพื้นที่ทดลองหนึ่งบริเวณก่อน จากนั้นเพิ่ม interact/ขุดแร่/ตีมอนผ่านกติกาเดิมทีละเส้นทาง
- ออกแบบโลก88×68ด้านเซิร์ฟเวอร์และเซฟทดสอบแยกก่อนเพิ่ม gameplay ในพื้นที่นอก bounds2D
- ทดสอบ/ตรวจ diff ทุกช่วงและอัปเดต TASKS.md พร้อม commit และผลจริง ไม่ merge สาขาทดลองเข้า main อัตโนมัติ

## ย้อนกลับ

เกมเดิมยังอยู่ main และมี backup branch ที่อ้างถึงฐาน2D เปิดเกมเดิมได้โดยไม่ต้องลบไฟล์3D หากต้นแบบมีปัญหาให้หยุด host แยกหรือกลับ commit บนสาขาทดลอง ไม่ force push main และไม่คืนฐานข้อมูลผู้เล่นจริงจากข้อมูลทดสอบ
