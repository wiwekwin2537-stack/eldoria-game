## 1. ลูปเกม / ลำดับโหลด

### ผู้เล่นเห็น
เปิดเว็บ → หน้าโหลดภาพเมือง + ขีด % → หน้าแรก (ล็อกอิน/สมัคร) → ล็อกอินแล้วเกมรีโหลด 1 ครั้ง → หน้า "เตรียมภาพฉาก" → เกิดที่วิหารจุดเกิดในเมืองเอลโดเรีย

### ลำดับโหลดจริง (index.html)
1. `<head>`: `000-cdn.js` (ตั้ง `ELDCDN`, ดัก `HTMLImageElement.src`) → `000-reset-eld4.js` (ล้าง localStorage 1 ครั้ง/เครื่องเมื่อ epoch ≠ `eld4`, ไม่ทำบน localhost เว้น `?epochtest=1`)

3. HTML เกม (`#wrap`, canvas `#c` 640×448 เริ่มต้น, HUD, ปุ่ม) → `002-fix123.js` (`SRV`, `srvNow()`) → `003-core.js` (localStorage ใช้ไม่ได้ → ใช้หน่วยความจำ) → `004-core.js`
