## ระบบ 2 — สกิลอาชีพ 6 ช่อง + สกิลพื้นฐาน + ร้านสกิล + แถบสกิล

### 1. ผู้เล่นเห็น/ทำอะไร
- **ผู้ฝึกหัด**: ซื้อสกิลพื้นฐาน 3 ท่าที่ **ร้านสกิล** (บ้านป้ายสมุดในเมือง) — ฟันวงพายุ 60🪙 · ลูกไฟ 80🪙 · เยียวยา 100🪙 · "เยียวยา" ใช้ได้ทุกอาชีพตลอดไป (ปุ่มเขียว 💚 `#sk4` แยก)
- **มีอาชีพแล้ว**: สกิลช่อง 1–3 **ปลดเองเมื่อถึงเลเวล** (Lv.5/15/30 ไม่ต้องซื้อ) · ช่อง 4–6 ถึงเลเวล (50/75/100) แล้วต้อง **ซื้อที่ร้านสกิล** 5,000 / 12,000 / 30,000 🪙 (เจ้าของสั่ง fix56) · ร้านโชว์ไอคอนสกิลจริง ปุ่ม "📖 เรียนสกิล · 🪙 ราคา"
- ปุ่มสกิล 6 ปุ่มบนจอ (มือถือ: วงคู่รอบปุ่มโจมตี ล็อกหน้าเดียวโชว์ครบ 6 — เจ้าของสั่ง v5.14) · ปุ่มที่ยังไม่ปลด = รูปสกิลมืด/ขาวดำ + 🔒 (162-fix135) · ปุ่มมีแถบคูลดาวน์ ตัวเลขวินาที ค่ามานาเล็ก ๆ ขอบทองเมื่อรอจังหวะต่อ
- สกิลช่อง 2 ของทุกอาชีพเป็น **คอมโบ 3 จังหวะ**: กดซ้ำภายใน 1.8 วิ = จังหวะถัดไป (ปุ่มขึ้น "2/3", "3/3") ครบ 3 จังหวะค่อยติดคูลดาวน์เต็ม · ถ้าหมดเวลากลางคัน คูลดาวน์ = `cd×(step/3+0.34)`
- **ลากเล็ง** (SKILLAIM46): กดปุ่มสกิลค้างแล้วลาก → เห็นเส้น/วงสีแดงบนพื้น (ทิศ ระยะ ความกว้าง พื้นที่) · ปล่อย = ร่ายไปทางนั้น · ลากไปมุมขวาบน (ปุ่ม ✕ ยกเลิก) = ยกเลิก · แตะเฉย ๆ = ร่ายเล็งอัตโนมัติ (`aimDir`: มอนในกรวยหน้า cos>0.55 ใกล้สุด) · สไนเปอร์ช่อง 5 "ซุ่มยิง" = กดค้างซูม/ลากล็อกเป้า/ปล่อยยิง
- จัดแถบสกิล: หน้าต่างสกิล แท็บ ⚔️ สกิล → ปุ่ม 1–6 ใต้การ์ดสกิล = ย้ายสกิลไปช่องนั้น (`setBar`) · ป้าย NEW บนสกิลใหม่ที่ยังไม่เคยจัด
- ใช้สกิลในเมือง/ร้านไม่ได้ ("ใช้สกิลต่อสู้ในเมืองไม่ได้") · ต้องถืออาวุธชนิดที่อาชีพใช้ ("ต้องถือคทาเพื่อใช้สกิลนักเวท") · ขี่สัตว์อยู่ → ลงอัตโนมัติ · ใช้สกิลยกเลิกการวาปกลับเมือง · ร่ายแล้วมีป้ายชื่อสกิลลอย (`castBanner`) + ท่าทางตัวละคร (055, 143)

### 2. กติกาและตัวเลข
**ลำดับเช็กตอนกดสกิล (รวมทุกชั้น)**: หยุดเกม/ประตู/ตาย/ตกปลา → ไม่มีข้อมูลสกิล → (ช่อง≥4) ยังไม่ซื้อ "ต้องเรียนที่ร้านสกิลก่อน" (088-fix56:6) → ยังไม่ถึงเลเวล "ปลดล็อกที่ Lv.X" → อาวุธผิดชนิด (031:2231, 084-fix52:18) → ในเมือง → คูลดาวน์ (ยกเว้นต่อคอมโบช่อง 2) → มึน/พุ่ง → มานาไม่พอ → หักมานา ตั้งคูลดาวน์ ร่าย
- **ล็อกกันกดรัว** หลังร่ายสำเร็จ: 0.64 วิ (ต่อคอมโบ 0.43 วิ) 032-fix1.js:67 · **คิวท่า**: กดสกิลอื่นระหว่างท่าค้าง (`P.stun>0` ภายใน 1.5 วิหลังร่าย) → จำไว้ ลองร่ายซ้ำทุก 40ms นานสุด 1.3 วิ (123-fix91.js:13-19)
