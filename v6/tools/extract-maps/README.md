# เครื่องมือดึงข้อมูลแมพจากเกมเดิม (ใช้ทำ `v6/src/data/maps/` ใน 1A-2)
- เปิดเกมเดิมในเครื่อง (`DATA_DIR=/tmp/eld PORT=8787 node server.js`) แล้วรัน `python3 v6/tools/extract-maps/run.py ไอดี รหัส dump.js dump.json` (หาโฟลเดอร์ tests/ ของเกมเดิมจากตำแหน่งสคริปต์เอง ไม่ฝังพาธ) · ใช้ไอดีทดสอบเท่านั้น ห้ามใช้ไอดีจริง
- อ่านค่าตอนเกมรันจริง (ตารางชน ขนาด จุดเกิด ประตู ตำแหน่งภาพ) → `python3 conv.py <โฟลเดอร์ที่มี dump*.json>` (หรือ env `EXTRACT_DIR` · ค่าเริ่ม = โฟลเดอร์นี้) แปลงเป็น `v6/src/data/maps/*.js` ของ repo เดียวกัน
- ค่าที่วัดได้จากเกมจริงชนะค่าในสเปกเมื่อไม่ตรงกัน (หัวหน้าอนุมัติ 30 ต.ค.)
- ไฟล์ผลดึง (dump*.json) ไม่เก็บใน repo
